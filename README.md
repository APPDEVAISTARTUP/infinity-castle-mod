# Infinity Castle Dimension (Fabric 26.3)

Dimension `infinitycastle:castle` - infinite Mugen Jou style castle (mega tower, floating rooms, bridges, lanterns, torii).

Commands:
- `/infinitycastle portal` - portal frame spawn hota hai tumhare saamne
- `/infinitycastle enter`  - seedha castle mein

Jar banana: ye folder GitHub repo mein push karo -> Actions tab -> "build" -> Artifacts -> `infinity-castle-jar`.
Chahiye: Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.162.0+26.3, Java 25.
